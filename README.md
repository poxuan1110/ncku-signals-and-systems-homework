# NCKU Signals and Systems - Homework Archive

Coursework archive for **Signals and Systems** at National Cheng Kung University.

## Contents

Each `HWn/` directory contains the original submitted materials in a browsable form.

| Homework | Included materials | Main topics represented by the work |
| --- | --- | --- |
| HW1 | PDF report and MATLAB scripts | Continuous- and discrete-time signals |
| HW2 | PDF report and MATLAB scripts | Convolution and deconvolution |
| HW3 | PDF report and MATLAB scripts | Laplace-domain system analysis, poles/zeros, frequency response |
| HW4 | PDF report, MATLAB scripts, and figures | Z-transform, discrete-time systems, stability, filter response |
| HW5 | PDF report, MATLAB scripts, and figures | DFT, FFT, and DTFT |
| HW6 | PDF report and PowerPoint presentation | Final homework submission |

The `original-submissions/` directory preserves the six ZIP files exactly as submitted, including their original filenames and folder structure.

## Running the code

The `.m` files were written for MATLAB. Some scripts use Control System Toolbox functions such as `tf`, `impulse`, `step`, and `bode`; HW4 also uses symbolic operations. Run individual scripts from MATLAB after opening the corresponding homework directory.

## Notes

- This repository is a course-work archive. Reports, figures, code, and original ZIP packaging have deliberately been retained as submitted.
- The reports include the student's name and student ID as part of the original submission format.
- This repository does not contain the official homework prompts or course handouts; any course-owned instructions should remain outside this archive unless their sharing terms are clear.
